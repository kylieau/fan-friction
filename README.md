# FanFriction: starter bundle

Drop everything in this folder into the root of the `fan-friction` repo (so `CLAUDE.md` sits at the top level), commit it, then open Claude Code in the repo and paste the prompt from `CLAUDE_CODE_FIRST_PROMPT.md`.

- `CLAUDE.md`: the context Claude Code reads automatically.
- `CLAUDE_CODE_FIRST_PROMPT.md`: the first prompt to paste.
- `docs/`: the build brief, product decisions, test nights and ratings, Kylie's logs, researched events.
- `design/wireframes/`: the current mockups. The full canvas is also published at https://claude.ai/artifact/FTTHBE2RUYZAme3usqu8E8 (titled "Crowd Clash Wireframes").
