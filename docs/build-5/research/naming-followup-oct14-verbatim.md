# Naming follow-up research: prompt and answer (verbatim, Oct 14 2026)

## Prompt

Follow-up to the naming review. These naming cases weren't settled. For each, recommend the best title wording for an event app's three lengths: chip (16 characters plus a designation), short (32 characters, 2 lines) and full (~64 characters, never cut). Give one alternative, and cite the official league or event conventions where they exist.

House rules already decided:
- Teams come first, then the round, joined by a middle dot.
- Use "vs." with a period at neutral sites; use "at" for home games.
- Preseason is a suffix ("· Preseason").
- Doubleheaders are DH1/DH2 on chips and Game 1/Game 2 in full names.
- Finals carry the year ("Super Bowl 2027"), dropped on chips.
- The artist goes before the tour.
- Full playoff words go on the event page; short forms go on chips.

Cases to settle:
1. MLB spring training (and Cactus/Grapefruit League naming)
2. All-Star games and skills events across MLB, NBA, NHL, WNBA and MLS
3. Tournament names (conference tournaments, bowl games, invitationals)
4. Pop-up shows with no venue name (open lots, temporary venues)
5. Comedy and theatre headliners: when to lead with the performer vs. the show title
6. Minor-league hockey playoff games with no game number published yet
7. The same event appearing twice from two sources with different titles: which title wins

End with any rule we should add to the house rules.

## Answer

The key distinction is the unit of attendance: one game, a whole session, a named production, or an individual performer’s show. Name that unit consistently.

Below, chip = identity + separate designation. Chip identities stay within 16 characters; short examples stay within 32, including spaces and punctuation. Full titles target 64 characters but wrap when necessary. Matchups and performer examples are illustrative, not fixture announcements.

1. MLB spring training
   Use Spring training, rather than Preseason. Cactus/Grapefruit League is secondary context, not a replacement for that description.
   Cactus League example
   - Chip: Reds + Spring training
   - Short: Cubs at Reds · Spring training
   - Full: Cubs at Reds · Spring training (Cactus League)
   Grapefruit League example
   - Chip: Cardinals + Spring training
   - Short: Mets at Cards · Spring training
   - Full: Mets at Cardinals · Spring training (Grapefruit League)
   Alternative: Use Cactus League or Grapefruit League as the chip designation, while retaining Spring training in short/full titles. This suits a dedicated spring-training view better than general discovery.
   MLB uses Spring Training, Cactus League, and Grapefruit League. Keep the actual ballpark in venue metadata; “at” follows the verified host assignment. MLB spring-training naming (https://www.mlb.com/spring-training)
2. All-Star games and skills events
   For a ticket covering the entire All-Star game/session, lead with the league event name. Do not invent a two-team matchup for a multi-team format.
   Recommended game titles:
   - MLB: Chip MLB All-Star + Game; short MLB All-Star Game; full MLB All-Star Game 2027.
   - NBA: Chip NBA All-Star + Game; short NBA All-Star Game; full NBA All-Star Game 2027.
   - NHL: Chip NHL All-Star + Game; short NHL All-Star Game; full NHL All-Star Game 2027.
   - WNBA: Chip WNBA All-Star + Game; short WNBA All-Star Game; full WNBA All-Star Game 2027.
   - MLS: Chip MLS All-Star + Game; short MLS All-Star Game; full MLS All-Star Game 2027.
   These are naming templates, not confirmation that each 2027 event has been scheduled.
   Name skills events by the actual competition:
   - MLB: Chip Home Run Derby + MLB; short MLB Home Run Derby; full MLB Home Run Derby 2027. MLB calls this the Home Run Derby, not a Skills Challenge. MLB event (https://www.mlb.com/all-star/home-run-derby)
   - NBA: Chip NBA All-Star + 3-Point, Slam Dunk, Shooting Stars, or Skills; short NBA 3-Point Contest, NBA Slam Dunk, NBA Shooting Stars, or NBA Skills Challenge; full expands to NBA Slam Dunk Contest 2027, for example. Use only competitions confirmed for that edition. Shooting Stars appeared in 2026; Skills Challenge should not be a permanent default. NBA Shooting Stars (https://pr.nba.com/2026-shooting-stars-field/), NBA Slam Dunk (https://www.nba.com/allstar/2025/slam-dunk-contest)
   - NHL: Chip NHL All-Star + Skills; short NHL All-Star Skills; full NHL All-Star Skills 2027. This follows the announced event name. NHL 2027 convention (https://www.nhl.com/news/topic/nhl-all-star/nhl-unveils-new-format-for-2027-all-star-weekend)
   - WNBA: Chip WNBA All-Star + 3-Point, Shooting Stars, or Skills; short WNBA 3-Point Contest, WNBA Shooting Stars, or WNBA Skills Challenge; full adds the verified year and complete competition name. The 2026 program includes Shooting Stars; earlier editions used Skills Challenge. WNBA 2026 program (https://www.wnba.com/allstar/2026), 2025 competition names (https://www.wnba.com/news/friday-night-events-att-wnba-all-star-2025)
   - MLS: Chip MLS All-Star + Skills; short MLS All-Star Skills Challenge; full MLS All-Star Skills Challenge 2027. MLS naming convention (https://bracket.mlssoccer.com/news/mls-all-star-skills-challenge-presented-by-at-t-kicks-off-in-queen-city-july-28)
   Alternative: When the record represents a separately selectable matchup, apply teams-first:
   - Chip: USA Stars + All-Star
   - Short: USA Stars vs. World · All-Star
   - Full: USA Stars vs. World · NBA All-Star Game 2026
   Use the edition’s actual team names. NBA’s 2026 format had three teams; hard-coded East vs. West would be wrong. NBA format (https://www.nba.com/allstar/2026/format)
3. Conference tournaments, bowls, and invitationals
   Individual game: teams first. Multi-game session or pass: tournament first. Never title a session as though it admits someone to only one matchup.
   Conference-tournament game
   - Chip: LSU vs. Florida + SEC semifinal
   - Short: LSU vs. Florida · SEC semifinal
   - Full: LSU vs. Florida · SEC men’s basketball semifinal
   Bowl game
   - Chip: Indiana vs. Bama + Rose Bowl
   - Short: Indiana vs. Bama · Rose Bowl
   - Full: Indiana vs. Alabama · Rose Bowl Game 2026
   Show College Football Playoff quarterfinal in a separate round field when applicable. A bowl is not automatically a final. The official 2026 event was a CFP quarterfinal at the Rose Bowl Game. Official Rose Bowl naming (https://rosebowlgame.com/news/2025/12/7/general-indiana-to-play-in-the-college-football-playoff-quarterfinal-at-the-rose-bowl-game-presented-by-prudential.aspx)
   Invitational game
   - Chip: Duke vs. Kansas + Maui
   - Short: Duke vs. Kansas · Maui
   - Full: Duke vs. Kansas · Maui Invitational
   Retain Invitational in the full name; do not generically rename every event “Tournament.” The organizer’s current sponsored name is Southwest Maui Invitational. Official event (https://www.mauiinvitational.com/)
   Alternative—for session admission:
   - Chip: SEC tournament + Session 1
   - Short: SEC men’s hoops · Session 1
   - Full: SEC men’s basketball tournament · Session 1
   Use the organizer’s actual session number and show the included games underneath. SEC explicitly distinguishes single-session and all-session tickets. SEC ticket conventions (https://www.secsports.com/ticketoffice)
4. Pop-up shows without a venue name
   Lead with the artist or named event. Missing venue information does not belong in the title.
   - Chip: Jesse Welles + Pop-up
   - Short: Jesse Welles · Pop-up
   - Full: Jesse Welles · Pop-up show
   Put a verified description such as “Open lot at [address]” in the location field. Use “Location to be announced” only when the organizer genuinely has not announced it; a missing feed value does not establish that.
   Alternative: Jesse Welles + Outdoor; short Jesse Welles · Outdoor show; full the same. Use this only when outdoors is confirmed and “pop-up” is not the organizer’s description.
   There is no universal official naming convention here. This is an editorial rule.
5. Comedy and theatre: performer or production first
   Comedy: Lead with the performer for a solo headline booking. Lead with the named show for a comedy festival, ensemble bill, or recurring branded show.
   Solo comedy
   - Chip: Ali Wong + Comedy
   - Short: Ali Wong
   - Full: Ali Wong—or Ali Wong · {verified tour name}
   Alternative: Ali Wong · Live for short/full. Prefer the verified tour name when available; “Live” adds little information.
   Theatre: Lead with the production. A famous cast member does not replace the show’s identity.
   - Chip: Waitress + Theatre
   - Short: Waitress
   - Full: Waitress · Touring production, when that distinction matters
   Alternative: Waitress · With {performer} in full, only when that performer is confirmed for the selected performance. Keep chip/short show-led.
   Broadway’s official listings identify productions by show title and treat creative/cast information separately. This supports production-first naming; it does not establish a universal comedy rule. Broadway League example (https://www.broadway.org/shows/hamilton)
6. Minor-league hockey playoffs without a published game number
   Omit the game number. Never guess it, and never print “Game TBD.” Date and time distinguish occurrences until the league publishes the series schedule.
   - Chip: Gulls + AHL playoffs
   - Short: Reign at Gulls · AHL playoffs
   - Full: Reign at Gulls · Calder Cup Playoffs
   Alternative—when the round is verified:
   - Chip: Gulls + Division SF
   - Short: Reign at Gulls · Division SF
   - Full: Reign at Gulls · Calder Cup Playoffs, Division Semifinals
   Once confirmed, append G2 to the chip designation and Game 2 to the full title.
   Use each league’s actual competition and round names: AHL Calder Cup Playoffs, ECHL Kelly Cup Playoffs. Do not copy NHL round names into every hockey feed. AHL naming and numbered schedules (https://theahl.com/news/schedules-set-for-2026-calder-cup-division-semifinals), ECHL conventions (https://echl.com/about/kelly-cup-playoffs)
7. Duplicate event, different source titles
   Neither raw title automatically wins. Merge the records, then generate one canonical title from verified facts.
   Recommended authority order:
   explicit editorial correction → official league/organizer → official venue or authorized ticket seller → aggregator. Use the latest confirmed information within that order. Recency alone should not let an aggregator override the organizer.
   Example sources: Chicago Cubs vs. Los Angeles Dodgers and Dodgers @ Cubs — Preseason.
   After confirming the Cubs host and the game is preseason:
   - Chip: Cubs + Preseason
   - Short: Dodgers at Cubs · Preseason
   - Full: Dodgers at Cubs · Preseason
   Alternative: If participants or host roles cannot be resolved confidently, preserve the official organizer’s complete title. Use a verified short identity for the chip; obtain an editorial short title if necessary. Do not parse an uncertain title into invented facts.
   Merge only after confirming the same occurrence and admission scope. A festival pass and a concert within that festival are not duplicates. Keep original titles and source provenance internally.
   This source hierarchy is a proposed Fan/Friction policy, not an official league convention.

Add these house rules:

- Name the admission unit: matchup, session, pass, competition, or production.
- Spring training is its own suffix; Cactus/Grapefruit League is secondary context.
- Unknown facts are omitted, never invented. Add game numbers, opponents, rounds, and locations when confirmed.
- Use edition-specific All-Star names and formats. Keep sponsor names in official-title metadata unless they are essential to recognition.
- Deduplicate before naming; generate titles from verified facts.
- Length limits govern compact versions, not the complete identity. Use approved short names; let full titles wrap beyond 64 characters when needed.
