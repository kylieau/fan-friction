03 · Friction vs occasion vs the night's read

Three different scales share one look. "Major" (occasion, meaning how big a deal) sits in the same pill slot as "Heavy friction" (what the event is up against), so a 70k Bruno Mars marked only "Major" looks calmer than a 2k show marked "Heavy." Bruno Mars has no friction pill because Low is hidden (by design), and the empty slot reads like missing data. The 4.3 in the header rates the whole city, not any single row. None of this is inconsistent. It's unexplained.
