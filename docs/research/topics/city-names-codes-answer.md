# City display names and three-letter codes: answer

Prepared 12 October 2026 for Fan/Friction. The brief listed the 26 metro names but not the current codes, apart from Tampa Bay = TPA. So the "Changes" section compares names against the brief. For codes, it compares each recommendation against the main airport code, which the brief sets as the default.

## How to read this

- **Figure labels.** Every figure is tagged as **measured** (counted or checked by me in this session), **announced** (stated by a team, league or government), or **estimated**.
- **Character counts are measured.** They count characters including spaces and the en dash.
- **Source status.**
  - **Verified** means I opened or retrieved that page during this research session.
  - **From memory** means the claim or the link domain comes from general knowledge and was not re-checked here. Every such item is repeated in the Self-audit.
- **Confidence ratings.**
  - **High:** multiple independent sources agree, or the fact is structural, such as an airport code.
  - **Med:** a judgment call with partial evidence.
  - **Low:** mostly my reasoning.

### The code rule I applied

The default is the main airport's IATA code. I depart from it only when both of these hold:

1. The airport code doesn't read as the city. Examples: it is named after the airport (ORD, JFK, IAH), or it is a cryptic Canadian Y-code.
2. A standard alternative exists that fans actually see daily, such as a scoreboard abbreviation, an IATA metro-area code, or the tourism board's own shorthand.

Where only one condition holds, I kept the airport code and noted the alternative.

#### Bay Area (SFO), high for the name, med for the code

**Covers**
- San Francisco: Giants, Warriors, Valkyries, Chase Center.
- Santa Clara: 49ers at Levi's Stadium.
- San Jose: Sharks, Earthquakes.
- Oakland: venues remain, but no MLB, NBA or NFL team as of 2026 (from memory).

**Name evidence**
- The NFL's Super Bowl LX organiser was the **Bay Area Host Committee**, and the NFL announcement framed the host as the "San Francisco Bay Area" ([host committee release](https://bayareahostcommittee.com/bay-area-to-host-super-bowl-lx-in-2026), verified).
- FIFA used "San Francisco Bay Area" for Levi's Stadium ([ESPN](https://global.espn.com/football/story/_/id/37629375/utils/enums), verified).
- The local NBC station brands itself NBC Bay Area ([example](https://www.nbcbayarea.com/super-bowl/bay-area-prepares-host-super-bowl-lx/3789075/), verified).

**Confusion risks**
1. "Bay" alone collides with Tampa **Bay**. Never shorten Bay Area to "Bay" on a chip or in search.
2. SFO reads as San Francisco only, so South Bay fans may see it as city-centric. There is no better standard code:
   - QSF is used as a Bay Area metro code in some booking systems, but in IATA's own list QSF is an airport in Sétif, Algeria ([Wikivoyage](https://en.wikivoyage.org/wiki/Metropolitan_Area_Airport_Codes), verified). Avoid it.
   - "QBA" appears in one award-search site's custom list ([seats.aero](https://docs.seats.aero/article/36-how-to-search-by-airport-city-or-region-code), verified). It is not a fan-recognizable code.

**Code:** keep SFO.

**Covers**

#### Kansas City (KCI recommended, MCI acceptable), med

**Covers**
- Kansas City, Missouri: Chiefs and Royals at the Truman Sports Complex; Current at CPKC Stadium.
- Kansas City, Kansas: Sporting KC; Kansas Speedway. (From memory.)
- **Watch list:**
  - The Chiefs announced in December 2025 that they will move to a new domed stadium in **Kansas City, Kansas**, near the Kansas Speedway and The Legends, for the 2031 season ([AP via Audacy](https://www.audacy.com/thesky973/news/kansas-city-chiefs-announce-they-will-leave-arrowhead-and-relocate-across-the-kansas-missouri-border), verified; announced, 2031).
  - The Royals' future site was still being decided in 2026. I saw only a headline about Kansas City approving Royals stadium funding and did not read the article, so treat it as unverified.

**Confusion risk:** the name must cover both states. Never append ", MO".

**Code**
- The IATA code is MCI, from the airport's original name, Mid-Continent International.
- Locals call the airport **KCI**. The city's own aviation department explains the mismatch ([KCUR](https://www.kcur.org/post/why-your-relatives-fly-mci-not-kci-when-they-come-kansas-city), verified; [flykc.com](https://flykc.com/about-us), verified).
- **I recommend KCI** because it reads as "KC" to fans and matches local speech.
- **Caveat:** KCI is not Kansas City's IATA code. KCUR says it once belonged to an airport in Indonesia and is not currently in use. I didn't verify that independently.
- If you need every code to be a real, current IATA code, keep MCI.

## 2. Changes

The current codes weren't in the brief except TPA. "Change" below means a change from the current name, or from the main airport code you would otherwise default to.

### Names

| Current | Recommended | Why | Confidence |
|---|---|---|---|
| Minneapolis–St. Paul | **Twin Cities** (switcher shows "Minneapolis–St. Paul" as secondary text) | 20 → 11 characters (measured); the name locals and local media actually use; avoids "Minnesota" ambiguity | med |
| Montreal | **Montréal** | Official tourism body spells it with the accent in English; same length; needs accent-folding in search | med-high |
| Dallas–Fort Worth | keep, add **DFW** short form | 17 characters exceeds your 14 threshold; DFW is the established regional shorthand | high |
| Mexico City | keep, add **CDMX** alias/short form | local usage; keeps English consistency with the other 25 | med |
| Bay Area | keep | supported by the Super Bowl LX host committee, FIFA, local TV | high |
| Tampa Bay | keep (decided) | Rays back in St. Pete for 2026 confirms the multi-city name | high |

### Considered and not changed

- **PHL vs PHI**: both recognized, so I kept the airport code.
- **SMF vs SAC**: SAC is a real but minor airport code. It's a close call, so I kept SMF.
- **YVR vs VAN**: YVR is plausibly as recognizable, so I kept it.
- **MSY, BNA, CMH**: obscure to outsiders, but there's no standard alternative.
- **SFO vs QSF/QBA**: the alternatives are non-standard, and QSF clashes with an Algerian airport.
