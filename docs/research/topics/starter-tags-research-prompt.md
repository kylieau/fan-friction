# Starter tags research prompt (Kylie, Oct 12 2026; drafted by Mock Mosaic)

I'm designing a personal log app for live sports and concerts (like Letterboxd for events). Users can add free-form tags to an event they attended or are attending/watching. I need a starter set of suggested tags shown to new users before they've made their own.

1. List the 20–30 most common things fans actually note or remember about a game or concert (e.g. promos/giveaways like bobbleheads, theme days, fireworks, milestones, weather, who they went with, special moments). Cover sports and concerts separately.
2. Look at how comparable apps handle suggested tags or labels (Letterboxd, Untappd, Goodreads, Strava, setlist.fm, ticketing or fan apps) and summarize the best practice for starter suggestions: how many to show, generic vs context-aware, and when to stop showing them.
3. Recommend a final starter set of 8–12 short lowercase tags that work across sports and concerts, plus any that should only appear for one or the other. Avoid anything corny, and flag tags that would be better as a structured field instead (e.g. seats).
Cite sources where possible.
