# Research brief: city type for every metro

## What this is for
Fan/Friction is a personal log of live sports and concerts, with a "friction" read computed for each night from public schedules: how many big events share a date, how close their start times are, and whether their crowds hit the same roads. It covers 26 metros: Atlanta, Austin, Bay Area, Boston, Chicago, Columbus, Dallas–Fort Worth, Houston, Kansas City, Las Vegas, Los Angeles, Mexico City, Milwaukee, Minneapolis–St. Paul, Montreal, Nashville, New Orleans, New York, Philadelphia, Phoenix, Sacramento, San Diego, Seattle, Tampa Bay (built as "Tampa", code TPA), Toronto, Vancouver.

Each metro has a type that sets the default travel assumptions when a venue has no measured data: how many fans drive, and how hard parking and exits are. Current types are provisional. Chicago has two prior answers that both say "hub", one noting the car share isn't established region-wide (Wrigley 2013: 36.7% driving; Ryan Field concert projection: 58%). The app wires only measured splits, plus sourced estimates marked as estimated.

## What I need, in this order

### 1. A type per city
Classify each metro as **transit hub** (most big-venue fans use transit), **mixed** (meaningful transit to some venues, driving to others) or **car-first** (most fans drive almost everywhere). If these three don't fit, propose a better set and say why.

### 2. Evidence
Give measured mode splits for fans at major venues (surveys, transit agency event ridership, team or stadium studies), with the year and venue for each.

### 3. Exceptions
List the venues that break from their city's type, such as a transit-heavy downtown arena in a car-first metro.

### 4. A default drive share
Give each city a default share of fans who drive: a single number only if a source supports it, otherwise a range labeled as an estimate.

### 5. Output table
Columns: city, type, default drive share, measured/estimated, exception venues, sources, confidence. Follow it with the cities whose provisional type you would change, and why.

### Self-audit
List every claim that rests on thin evidence, anything you guessed, and what I should check by hand: the source link for each, and an example I can open in a browser.
