## Coverage and where the evidence was thin

All 139 rooms in the brief are covered, in the brief's order, one row per name.

- **Kinds used:** former / spelling / another room / unknown. **MISSING** marks a name the room used after 1990 that the list on file lacks.
- **"not checked"** means the row was classified from the name alone, with no source opened. **"(memory)"** marks a date that was not looked up; verify it before relying on it.
- **Wikipedia** is labeled as such and used only where nothing better turned up.

**Thin or unresolved evidence:**
- **Dates not found:** Luedecke Arena (Austin); the date "Auditorium" became "Arena" in Dallas; the Michigan Lottery naming date; Astroarena→Reliant Arena; the Reliant Arena Pavilion's new name; the PNC Stadium start (Houston); the day Everwise was announced (Indianapolis); the Thousand Oaks sponsor names; the end of the Cox Pavilion name; the post-World Cup return to Estadio Banorte.
- **Other gaps:** The Rave II's room-name dates; the Irving Plaza and Paramount sponsor tags; TD Place's third one-year sponsor; RCGT Park after 2021; the end of Platinum Living at Quarry Park; Canada Hockey Place's exact window.
- **No source found:** Southeast Sales Powersports Stadium; Rick Majerus Court / Jerry Huennekens Gymnasium; Umpqua Bank Grandstand; "Utah State Fairpark Arena" and "Florida State Fairgrounds Amphitheatre" as real names.
- **Memory only:** Canadian Tire Centre; Huntsman Center.
