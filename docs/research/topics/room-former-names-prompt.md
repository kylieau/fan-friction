# Research brief: when each room's former names were in use

Status: open. Written Oct 22, 2026 by Claude Code, at Kylie's request (Oct 22, 2026, afternoon: "yes, your lean for both!", to `docs/archive/proposals/room-names-proposal.md`). For any research model that can browse.

## What this is for
Fan/Friction is a personal log of live events (sports and concerts). People log nights going back years, and each night shows the room under the name it had **on that date** (a 2003 Celtics game was at the FleetCenter, not TD Garden). Each room on file has a list of names in order, and a name takes effect on its start date. A name with no start date never shows on any date, so an old night falls to a later name.

The 139 rooms below each carry at least one name with no start date that looks like a real former name. We need the date each name on the room's list took effect, with a source, so every past date shows the right name.

## The question
For **each room in the table**:
1. Give the **start date of every name on its list** (not only the undated one): the official renaming date when one was announced (day, month and year if published; else month and year; else the year), and the name in use before it. The first name needs no start date, only the year the room opened under it.
2. Sort each undated name into one of these:
   - **former name**: the room really went by it. Give its years.
   - **spelling**: a short form, a seller's or a school feed's spelling, or a translation of a name the room has used. It should never be shown. Say which name it spells.
   - **another room**: it names the building around the room, or a different room in the same building (a concert hall inside an arts center). Say which.
   - **unknown**: no source found. Say what you looked at.
3. Flag any name on file that **is wrong for this room** (never used for it), and any **missing name** the room went by after 1990 that the list lacks, with its dates.
4. Give **one source per date** (the venue, team, school, city or league; a contemporary news report; Wikipedia only when nothing better exists, labeled so). When two sources differ (an announcement date vs. the day the signs went up), give both and say which kind each is.

Keep the answer to the table's rooms, in the table's order, one row per name. Columns: city, room (shown today), name, kind (former / spelling / another room / unknown), start date, end date, source, note. Say at the top how many rooms you covered and where the evidence was thin.
