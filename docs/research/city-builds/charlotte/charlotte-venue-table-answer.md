# Charlotte — Fan/Friction city research answer

**Answer date:** 13 October 2026 (all sources accessed this date unless a different date is shown).
**Scope of this pass:** public sources only, fetched through normal web search/fetch. Every number below links to the page it came from. Where nothing was found, the cell says **gap** and the gaps list says what was searched.
**Labels used:** *official* = venue/team/league/university/government/organizer page; *reported* = news outlet or reference site quoting a figure; *estimated* = a figure the source itself calls an estimate. Capacity is never used as attendance, and attendance is never used as capacity.

## 1. Name, code and recommended boundary (Gap item 1)

| Field | Recommendation | Evidence |
|---|---|---|
| Display name | **Charlotte** | Local clubs brand with the city name, e.g. Charlotte FC's own schedule release uses "CLTFC" ([Charlotte FC, 20 Nov 2025](https://www.charlottefootballclub.com/schedule/2026)). |
| Short form | **CLT** | ESPN's match pages render Charlotte FC as "CLT" ([ESPN, 28 Oct 2025](https://www.espn.com/soccer/report/_/gameId/760085)). |
| Three-letter code | **CLT** (lead confirmed) | As above; no conflicting local three-letter usage found. |
| Why not a Tampa Bay–style regional name ("Carolina"/"Carolinas") | Keep **Charlotte**. "Carolina" is a shared label, not a Charlotte-specific one: the Hornets call themselves "the NBA team of the Carolinas" while playing preseason games in Greensboro and North Charleston ([Greensboro Complex, 2025](https://www.gsocomplex.com/news/detail/charlotte-hornets-to-take-on-memphis-grizzlies-in-nba-preseason-action-in-greensboro)), and a different-market club, Carolina Core FC (High Point/Triad), also uses "Carolina" ([2026 MLS Next Pro season](https://en.wikipedia.org/wiki/2026_MLS_Next_Pro_season)). A regional name would invite Triad/Raleigh matches. | — |
