## Judgment calls the builder made that Kylie may want to revisit

These are places the code picked one reading where the decision had two, or did something no decision asked for. None is a bug.

1. **"Away" on a home game the app cannot place.** A row reads "Away" whenever the game has no catalog event, and ESPN links a game to an event only when the venue name maps to a known room in the host's city. So a home game at a renamed or unmapped building, or at a neutral site in a covered city, also reads "Away". The decision's own word, but misleading on screen; "No read" would be truthful. (`src/components/useFavoriteRows.ts:92`; `src/data/sources/espnSource.ts:1368-1372`)
2. **Tapping one Fave while All is on picks only that one** (the opposite reading, unchecking that one, is as plausible). Recorded as a lean. (`src/components/FollowingSheet.tsx:137-144`)
3. **Filters persist per device for the session**, so a filter survives a tab switch and an app relaunch within the session. Recorded. (`src/screens/FollowingScreen.tsx:177-200`)
4. **Done is disabled with zero favorites** on the picker, so from the empty tab's "Add a Fave" the only exit without picking one is Back. (`src/screens/FavoritesScreen.tsx:248`)
5. **Browse by league is ordered by team count**, so "College men's basketball" tops the list above MLB and the NBA. A fixed major-league order may read better. (`src/screens/FavoritesScreen.tsx:40-45`)
6. **The sheet's sub-line collapses every college league to "College"**, hiding men's and women's there; the long name beside it carries it. (`src/components/FollowingSheet.tsx:40`)
7. **Artist rows repeat the artist** when the listing is the artist's bare name, and venue rows repeat the venue in the facts line under a lead that already names it. (`src/components/useFavoriteRows.ts:109, 129-134`)
8. **Following both sides of one game:** a covered game shows once, from the first-listed Fave's side; an uncovered one shows twice. (`src/components/useFavoriteRows.ts:73-75`)
9. **The Map sheet's "whole day" for the occasion tag is every event at a known venue**, where the decision says the city's whole day. Already in the builder's report. (`src/screens/MapScreen.tsx:130`)
10. **No Escape key or focus handling on the Show and manage sheet**, unlike the search sheet and the Settings panel. (`src/components/FollowingSheet.tsx:88`)
11. **Two readers of a program's side.** The row-label code (`src/lib/eventTitle.ts`, `sideOf`) and the name code (`src/data/teams.ts`, `programSide`) each read the side from league and name with their own patterns, and the chip codes there spell hockey MHKY where her list says MIH. One reader would have prevented G-fixed-1 below.
